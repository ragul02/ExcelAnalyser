# AI Insights - Quick Start Guide

## 🚀 Start Using AI in 3 Steps

### Step 1: Run the App
```bash
npm start
# or
npm run electron:dev
```

### Step 2: Load Data
- Click "Import" and select your Excel/CSV file
- Wait for data to load
- You'll see row/column count in the status bar

### Step 3: Enable AI
- Click the **"Insights"** tab
- Look for the **🤖 AI Insights** panel on the right
- Click **"Enable AI Insights"** button
- Wait 2-3 seconds for initialization

## 💬 Try These Questions

Copy and paste these to test:

```
What is the total revenue?

```

```

```

```

```


## 🎯 What You'll Get

For each question:
- ✅ Natural language answer
- ✅ Confidence score (0-100%)
- ✅ Execution time
- ✅ Chart recommendation
- ✅ One-click "Create Chart" button

## 📊 Example Flow

```
1. You ask: "What's the total revenue?"

2. AI responds: "The total is $125,450 (from 234 records)."
   Confidence: 95%
   Recommended: KPI chart

3. Click "Create Chart"

```

## 🆘 Troubleshooting

**AI won't enable?**
- Check browser console (F12) for errors
- Try refreshing the page
- Ensure modern browser (Chrome 90+, Edge 90+)

**Slow performance?**
- Close other browser tabs
- Check Settings → memory usage
- Try with smaller dataset (< 100K rows)

**Question not understood?**
- Try rephrasing
- Use exact column names
- Click suggested questions for examples
